# Internal working notes

These files are working notes, not user documentation: the phase plans and roadmap (`PLAN.md`, `plans/`), the acceptance matrix (`TEST_MATRIX.md`), and records of physical test runs (`evidence/`, `spikes/`, `native-capture-prerequisites.md`). `AGENTS.md` sends coding agents here, so the paths stay stable. Public docs in `docs/` and the README do not link to this folder. A finished plan leaves by becoming an ADR entry in `docs/DECISIONS.md`, a public page, or a deletion, and git history keeps the old text. Evidence leaves when nothing public cites it.
