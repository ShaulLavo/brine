# P08-06 source verification

This change implements the approved reservation and lifecycle contract. It does
not claim a real UDP deployment, remote packet delivery, a reboot drill, or
working UDP inode diagnostics on the Pi. Those physical gates remain P08-08.

## Executable coverage

- `internal/store/udp_transition_test.go` runs the real SQLite transitions,
  idempotent preparation/reversion, move ordering, family isolation, concurrent
  endpoint claims, terminal-state refusal and retirement atomicity.
- `internal/inventory/udp_proof_test.go` exercises the real collector proof with
  synthetic OS/runtime responses. Missing inode, changed FD, changed unit,
  duplicate/foreign sockets and unknown mappings refuse readiness or absence.
- `internal/inventory/udp_resume_test.go` combines actual SQLite claims with the
  production collector. The family's unpublished discovery facts rebuild to the
  original bytes. A real socket and another family's claim remain visible.
- `internal/host/udp_test.go` binds proof requests to the exact stored plan,
  prepared operation family and rendered unit hash. Both host and apply
  freshness comparisons rebuild only their own expected preparation.
- `internal/apply/udp_test.go` covers create, retain, move, release, stop/start,
  restart, compensation proofs, unknown-result read-back and stale resume.
- `internal/apply/udp_subprocess_test.go` runs the executor in child processes
  with a real SQLite journal/reservation store and synthetic runtime adapters.
  The parent sends SIGKILL before an effect, after its durable transaction but
  before its outcome receipt, and after the outcome receipt for preparation, readiness,
  reversion, compensation, commit and removal boundaries, then inspects and
  recovers the durable operation. Real SQLite resolution tests also cover failed
  UDP removal preparation/proofs, a late remnant and committed-error read-back.
  Retirement repeats endpoint absence immediately before its database transaction.
  An uncommitted unknown route/commit remains
  recovery-required rather than replaying a mutation.
- `internal/apps/udp_rollback_test.go` restores the selected historical endpoint
  under the current grant, including occupied, revoked and out-of-grant cases,
  an earlier incarnation and rollback to HTTP-only.
- `internal/store/udp_archive_test.go` checks retirement refusal for every live
  claim state, released-only success, late claims from another SQLite handle,
  unreadable state and safe abandonment. The host persistent-UDP test confirms
  that normal writer-schema access remains available after a UDP commit.

## Reproduction

Use a task-owned temporary directory on a filesystem with durable fsync support.
On the shared workstation, use the heavy runner and `/home/shaul/tmp`.

```sh
go test ./internal/{plan,store,inventory,apply,host,apps} -run UDP -count=1
bash scripts/test-ci.sh
bash scripts/check.sh all
bash scripts/check-spacetime-runtime.sh
git diff --check
```

The coordinator's handoff records final gate results and exact source head.
No dependency, version or quality baseline is widened. Test-created processes,
SQLite stores, files and build output are removed; shared caches are retained.
