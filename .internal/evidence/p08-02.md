# UDP planning and reservation contract

Status: P08-02 implementation evidence, November 1, 2026. UDP execution remains
unavailable. This is not a publication, readiness, rootless runtime or remote
packet-delivery report.

## Scope

The strict app table, exact operator grant, normalized desired input, optional
plan allocation/transition, relevant decision-fact projection and configuration
diff live in `internal/spec`, `internal/policy`, `internal/target` and
`internal/plan`. The CLI exposes exact UDP grant plan/apply actions through the
existing operator channel. Snapshot fixtures require the new observations.
`internal/inventory` records address-specific unowned UDP sockets from extended
`ss` output and local addresses from bounded `ip` output.

`internal/store/migration_v34.go` adds immutable release-head incarnation IDs
and retained reservation rows with unique endpoint, staged-claim and holder
indexes. Legal state edges are enforced by real SQLite constraints and triggers.
State and inventory read APIs retain stopped claims. No runtime reservation
preparation/commit/compensation engine is exposed by this task.

Direct renderer, host, apply, recovery inspection and resolution reject UDP.
Release commits and retirement also reject live UDP involvement. Conflict plans
have no executable changes, including lifecycle/removal previews. No parser,
policy or store test authorizes a real host or operator policy mutation.
